# Open product decisions

Only decisions that materially change the implementation are listed here.

## P0 before contract implementation

1. Final name and symbol: `ATAI` is the user's preferred candidate, pending
   explicit acceptance of existing token and public-company ticker collisions.
2. Confirm or replace the `100,000,000` fixed-supply default; keep `9` decimals.
3. Approve or amend the recommended `42/12/13/5/20/8` model, including founder
   18→60 and team 12→48 no-catch-up schedules.
4. Define initial utility that exists at launch without promising investment
   return or project ownership.
5. Choose legal entity and launch jurisdictions and approve the exact holder
   rights/non-rights before production contracts.
6. Name independent Admin, Treasury and Emergency signers. Admin/Treasury signer
   overlap must remain below threshold; different Safe addresses alone are not
   isolation.

## P0 before public liquidity or airdrop

1. Refreshed token classification memo and required Token Facts Pack.
2. Eligibility, consideration, privacy, Sybil and retrospective snapshot rules
   for each airdrop wave.
3. Public pool depth, ratio, custody, conflicts and LP withdrawal policy.
4. Independent smart-contract audit and public incident response contacts.

## P1 after the first vertical slice

1. Governance activation criteria and how Solana holders participate fairly.
2. Community-grant policy, budget cadence and reporting format.
3. Whether the code is published under Apache-2.0 and how brand assets are
   separately protected.
